CodexBar is a local, read-only usage dashboard for user-owned provider accounts. It has no CodexBar account, subscription purchase, inference service, or HemSoft backend for provider credentials or usage data. Provider-specific authorization connects the user's existing service account; it is not social sign-in to a CodexBar account.

The app opens without configuring an account. Live cards require reviewer-owned provider accounts or API keys, and no paid account or shared review credentials are supplied. Add a connection from Settings > Accounts & Groups > Add Account. Each connection can be removed independently. There is no customer demo mode; synthetic values are limited to development fixtures, screenshots, and tests.

ChatGPT / Codex and OpenCode Go + Zen offer browser or private sign-in. OpenCode approval includes workspace selection. Google Gemini uses a private Google website sign-in window for consumer usage and Google OAuth with PKCE for coding usage, linked only after same-account confirmation. Grok uses xAI device authorization and verifies identity and consumer usage access before saving a token. Service account verification or subscription limits may prevent live metrics from being available.

Greptile review activity and billing renewal are separate. Existing API-key accounts retain review activity. Billing renewal requires an account-scoped dashboard session saved in Keychain. The current temporary embedded browser does not reliably support fresh Google-backed billing sign-in or reconnection. Native OAuth can verify identity but does not authorize the dashboard billing endpoint; that provider compatibility work is deferred. Saved verified sessions can still return actual renewal dates. No manual cookie or token transfer is required or offered as a workaround.

GitHub Billing authorization is separate from GitHub Copilot. Its permission disclosure explains the repo, admin:org, and user scopes. Those scopes can permit repository, organization, team, or profile changes, but CodexBar's billing data requests are read-only; it does not modify repositories, organizations, profiles, or follows. Personal billing and organization allowances depend on the authorized account and GitHub's available data.

Google session credentials and provider OAuth tokens can grant access broader than usage monitoring. The app discloses that sensitivity during setup, stores retained credentials in each account's own Keychain entry, and uses them only for the documented authorization, identity, renewal, and read-only usage requests. Disconnect removes the local saved credential, not the provider's authorization grant. See the privacy policy for endpoint and retention details.

Widgets show saved snapshots after the iPhone app refreshes provider data. The embedded Apple Watch companion and complications receive presentation-only snapshots through Watch Connectivity; they do not receive credentials or make provider requests. iOS and watchOS control background refresh timing.

Optional GitHub service-status monitoring uses GitHub's public status endpoint without account credentials. Optional feedback previews non-secret diagnostic categories before opening an email draft or public GitHub form. Nothing is sent until the user takes the corresponding action. CodexBar contains no advertising, analytics, or third-party crash-reporting SDK.
